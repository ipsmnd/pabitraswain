# Pabitra Swain — Portfolio Website

A modern, dark-themed single-page portfolio website for a Frontend Developer & UI/UX Designer. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step, just open and go.

## ✨ Features

- **Dark / Light theme toggle** — persisted through a `data-theme` attribute, with a smooth color transition.
- **Animated space background** — a live `<canvas>` starfield, drifting aurora orbs, and a glow that follows the cursor.
- **Hero section** — gradient animated name, typewriter effect cycling through roles, pulsing "available for work" badge, and floating experience card.
- **Scroll reveal animations** — sections, cards, and timeline items fade in with staggered delays via `IntersectionObserver`.
- **Animated skill bars** — progress bars fill from 0% to their target when scrolled into view.
- **Animated counters** — years of experience, projects, and tech stack numbers count up on entry.
- **Filterable project gallery** — filter by *All / Website / UI/UX*, with staggered entrance animations and 3D tilt on hover.
- **Lightbox** — click any project to open a full preview with keyboard (← → Esc) and touch-swipe navigation.
- **Marquee tech strip** — infinite scrolling pills of skills, pauses on hover.
- **Testimonials carousel** — auto-advancing, with pagination dots, arrow controls, and swipe support.
- **Fully responsive** — mobile hamburger nav, single-column layout, and touch-friendly controls under 860px.
- **Accessibility touches** — keyboard-navigable gallery (`tabindex`, `Enter` to open), ARIA labels, and reduced motion respect via `@media (hover: none)`.
